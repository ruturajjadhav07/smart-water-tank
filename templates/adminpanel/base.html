About the Smart Water System

The Smart Water System is an innovative solution designed to automate water level monitoring in tanks, ensuring efficient water management and conservation. Using IoT sensors, the system provides real-time data on water levels, helping users avoid overflow and shortage situations.

It supports multiple buildings and tanks, offers a dashboard for both users and admins, and promotes sustainability through features like notifications, logging, and analytics.
